## 4 · Tuzaklar — bunları bilmeyen yeniden düşer

**1. `next dev` ile hiçbir istemci etkileşimi çalışmaz.**
CSP'de `unsafe-eval` yok, Next dev modülleri `eval()` ile çalıştırıyor →
React hiç hidrate olmuyor. Konsolda `EvalError: Evaluating a string as
JavaScript violates ... script-src`. Bugün lightbox bir süre bozuk sanıldı,
sebep koddu değil CSP'ydi.
→ Etkileşim testi için **üretim derlemesi**: `npm run build`, sonra
`preview_start` ile `frontend-prod` (`.claude/launch.json`, port 3100).
DOM'u `javascript_tool` ile sorgula.

**2. Dev sunucusu çalışırken `npm run build` çalıştırma.** İkisi aynı `.next`
dizinini kullanıyor; dev sunucusu bozuluyor (tüm chunk'lar 404 + MIME
`text/plain`). Olursa `.next`i sil, yeniden başlat.

**3. `anime.service.ts` içindeki `payload as unknown as object` dönüşümlerini
SİLME.** `eslint --fix` "gereksiz" diye kaldırmak ister, kaldırınca derleme
kırılır (Prisma `InputJsonValue` index imzası istiyor). Gerekçesi kodda
yazılı. Backend'de `npm run lint` çalıştırma, `npx eslint <yol>` kullan.

**4. Canlı veriyle yerel doğrulama.** `frontend/.env.local` içindeki
`NEXT_PUBLIC_API_URL`i `https://api.kuronexus.com` yap, işin bitince
**geri koy**. Basic Auth kapısı devreye girmiyor (`middleware.ts`
`NODE_ENV === "development"` iken atlıyor).

**5. Coolify.** Migration içeren deploy'larda backend ~3 dakika 503 veriyor
(konteyner yeniden başlıyor) — panik yok, bekle. Bugüne kadar iki kez de
kod dışı arıza oldu: konteyner `Exited` kaldı, bir deploy `/artifacts`
klasörü dolu diye düştü. Tekrarlarsa önce `df -h`.

**6. Satır sonları.** Repo dosyaları karışık LF/CRLF. Script'le metin
değiştiriyorsan şablonu dosyanın kendi satır sonuyla eşle, yoksa `includes`
hiçbir zaman tutmaz.

**7. Commit mesajları.** PowerShell here-string'i bozuyor; mesajı dosyaya
yazıp `git commit -F <dosya>` kullan.
